# six‑grade‑workstation
六年级全学科离线学习工作台，单文件HTML，零外部依赖，本地双击浏览器直接打开。

## 📚 功能板块
1. 📖 语文：部编六上/六下课内成语、典故、旧知寓言复习
2. 📐 数学：六年级核心概念、公式、易错知识点卡片
3. 🔤 英语：六年级重点单词、短语、句型卡片

## 使用
下载 `Artifacts/六年级全学科学习工作台.html`，双击直接打开，完全离线。

## Agent提示词
prompts/ 目录存放完整Agent指令
- `.md`：知识库阅读归档版本，用于Obsidian查阅、编辑、双向链接
- `.txt`：plaintext纯文本，交给WorkBuddy读取生成HTML

## 仓库说明
本仓库只存放代码产物与Agent指令集；Obsidian知识库Vault和本仓库物理分离，不提交到此仓库。
